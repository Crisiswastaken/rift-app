# Agents

This repo ships APKs and GitHub issues. Do not add app source here.

- Releases are the APK. `*.apk` is gitignored.
- The website pins `/rift.apk` at a tag and file name. A new tag with a new file name needs a matching change in Rift-web `vercel.json`.
- Tested games are decided in the app source (`games/Beta.kt`), not in this README. Update the table when a release changes that set.
- Issue templates are `.github/ISSUE_TEMPLATE/`.
